# Nova DSO Tracker v7.0.0

**Release Date:** 2026-10-19

## Much faster

- **Almost everything is now calculated in your browser instead of on the server** - the dashboard object table, the status strip, the graph view day, month and year charts, the Outlook tab, the yearly heatmap and the Imaging Opportunities list. They use the same rules the server uses, so the numbers are practically the same, but what took seconds (and for Outlook up to two minutes) now takes a few milliseconds. If your browser can't do the work, the server still does it, so nothing breaks.
- **The dashboard table keeps itself up to date** - in live mode it is recalculated every 60 seconds from the data already on the page, with no request to the server. The status strip's clock updates every minute in the same way.
- **Pages carry much less data** - the dashboard's journal rows and the graph page's selected session no longer include the stored log data (about 50 KB per session), the Framing Assistant's object list is fetched only when you open it, and a large chart library is loaded only when a tab that needs it is opened, instead of a few seconds after every page load.

## Things that look different

- **Moon illumination is now measured at local midnight on every page** - previously different pages measured the Moon at different moments. Values move by a few points, and about 10% of Outlook suggestions change.
- **Live values use the exact current time** - the table's current altitude, azimuth and trend now use the current moment instead of the nearest sampling step.
- **Heatmap rows** - Objects that would have shared the same label now each get their own row, with the object name added to tell them apart.
- **Heatmap week labels and tooltips are translated** - the week labels now follow the page's language, and the tooltip ("Week:", "Score:") and the partial-load messages are translated too.
- **Imaging Opportunities dates** - shown as 18.10.2026 instead of 18/10/2026.
- **The graph view has a location selector** - the Location in the status strip is now a dropdown. Sessions open at their own location, sessions without one stay on the page's location, and the date information and Imaging Opportunities follow the location you pick. Inactive locations can't be selected.
- **Name suggestions when adding an object** - after a SIMBAD lookup, the descriptive names found for the object appear under Common Name and can be clicked to fill the field in.
- **"This object is already in your library."** - adding an object you already have now says so and leaves the form as it was, instead of looking up the coordinates again.
- **The Framing Assistant's sky view** - the Aladin layer panel is hidden, and the credit for the survey image you are looking at is shown in the corner.
- **The dashboard loading message** - on the browser path the loader shows only "Calculating…" (the "0 / 0" counter and the progress bar were meaningless there and are gone), and it only appears if loading actually takes a moment.

## Fixes

- **Editing an object no longer clears fields** - a save that doesn't send every field leaves the others as they were.
- **Projects no longer change an object's pin** - creating, editing, retargeting or deleting a project used to set or clear the object's pinned state. The pin is yours to set.
- **Sun events on the graph could be overwritten** - the dashboard's own request for sun event times was writing into the shared values, so the graph's data could pick up extra keys and a growing error text. The two are kept separate now.
- **Chart labels kept their colour** - the Now and transit labels on the graph could turn dark grey when the chart was ready before the theme was applied. They stay red.
- **Outlook** - a late answer from the server can no longer overwrite the table the browser has already built, or start a second calculation.

## For self-hosters

- **No database changes.** Nothing to migrate, no columns added.
- **New read-only endpoints:** `/api/desktop_inputs`, `/api/desktop_library`, `/api/journal_sessions` and `/api/framing_objects`. `/api/mobile_up_now_inputs` and `/api/get_desktop_data_batch` are unchanged.
- **`/graph_dashboard/<object>?format=json`** - session rows no longer carry the four log columns (`log_analysis_cache`, `asiair_log_content`, `phd2_log_content`, `nina_log_content`). Every other key is unchanged.
- **`/api/get_plot_data`** - `sun_events.current` is back to exactly the five event keys; it could previously gain `date`, `time`, `phase` and `error`.
- **`/api/desktop_inputs`** has additional fields used by the browser.
- **Cache versions were bumped** (Outlook v3 to v4, heatmap v6 to v7), so the first Outlook and heatmap load after upgrading recalculates.
- Dependency updates: Werkzeug 3.1.9 (security fix, `safe_join` on Windows NTFS device names), urllib3 2.8.0, PyJWT 2.15.0.
- **Back up your `instance` folder before you upgrade.**
