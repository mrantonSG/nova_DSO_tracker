# Nova DSO Tracker v6.3.0

**Release Date:** 2026-08-12

## New Features

- **Catalog Import Conflict Review** - when importing objects that already exist in your catalog, a new conflict-resolution modal lets you compare field-by-field (name, magnitude, size, surface brightness, image URL, description) and choose which values to keep. A notification badge in the header shows how many conflicts are pending review, and a dedicated tab on the Objects page opens the conflict list.
- ASIAir / PHD2 / NINA log uploads now validate file extensions on the add-route and edit routes - only `.txt` files are accepted for ASIAir/PHD2, and `.log` uploads from Chinese-language ASIAir devices are rejected with a clear message.

## Bug Fixes

- Journal objects API now uses `Project.status` instead of the deprecated `active_project` field - the "In Progress only" filter in the journal's object switcher works correctly after completing or reopening a project.
- Catalog import no longer crashes with an `UnboundLocalError` when processing certain objects - the enrichment pipeline handles all catalog types without crashing.
- Resolving one conflict in the import modal no longer clears your pending changes for other fields - each field's state is now tracked independently.
- Header tab button correctly updates its active state after resolving conflicts in the modal - no more stale "resolved" badge after you fix a conflict.
- Numeric-string false positives on magnitude, size, and surface brightness conflicts are suppressed - numeric values that happen to be stored as strings no longer trigger spurious conflict warnings.
- Long field names in the conflict-review table are now wrapped instead of overflowing - column widths balance properly and no text is clipped.
- The catalog import confirm dialog has been translated into all 5 supported locales (German, Spanish, French, Chinese, Japanese).
- AI-generated DSO notes are now more concise (100–150 words, flat tone) - no narrative structure or filler.
- Session summary prompts include a fallback for legacy guide columns (`guide_pixel_um`, `guide_FL_mm`) - older rig data displays correctly in summaries.
- The "Today" button on the dashboard now appears before the Day/Month/Year view buttons, matching user expectations.
- The "Today" button no longer breaks when the month select option is an unpadded integer (e.g., `8` vs `08`) - the filter handles both formats.
- Day View, Month View, and Year View labels are now correctly translated in all 5 locales - previous versions showed "Saved views" or partial translations for these entries.
- Flash messages rejecting Chinese-language ASIAir log uploads are now translated in all 5 locales.
- Graph view tracking event fires before any early return - analytics data is no longer silently dropped for some sessions.
- JavaScript translation strings are properly escaped via `tojson` - the French locale no longer throws syntax errors from embedded quotes.

## Improvements

- The catalog import conflict-review entry point has been moved from the header into a dedicated tab on the Objects page for a cleaner layout.
