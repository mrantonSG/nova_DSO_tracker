# Nova DSO Tracker v6.7.1

**Release Date:** 2026-09-27

## Bug Fixes

- **Session logs in journal backups** - the "Download Journal Photos" ZIP now also contains the ASIAIR, PHD2 and N.I.N.A. log files attached to your sessions (under `logs/<type>/`). Importing the ZIP restores them; existing log files are never overwritten. The download now also works if you have logs but no photos.
- **N.I.N.A. logs in journal export/import** - N.I.N.A. log references were missing from the journal YAML export and import; they are now included like ASIAIR and PHD2 logs.
- **Journal import no longer takes over other users' projects** (multi-user mode) - importing a journal that contained a project ID already owned by another user moved that project to the importing user. The other user's project is now left untouched: your own project with the same name is reused, or a copy is created for you, and the imported sessions are linked to it.

## Heads Up

- To move a journal including session logs to another instance, import both the journal YAML and the Journal Photos ZIP.
