# Nova DSO Tracker v6.4.1

**Release Date:** 2026-09-04

## Bug Fixes

- Fixed clipboard copy failures in the graph view (RA/Dec readout, framing URL, and ASIAIR/N.I.N.A. mosaic export) - a new `copyToClipboard()` helper falls back to `document.execCommand('copy')` when `navigator.clipboard` is unavailable (non-secure/non-HTTPS contexts), instead of throwing a `TypeError`.
- Fixed a `ReferenceError` on "Copy Framing URL" and on inserting a framed target into a project - `buildFramingQuery()` was scoped inside `openFramingAssistant()` and unreachable from `copyFramingUrl()` and the Aladin insert-into-project handler; it's now defined at the top level.
