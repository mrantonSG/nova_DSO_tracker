# Security Policy

## Supported Versions

Security fixes are applied to the latest release only. Please update to the newest version before reporting.

## Reporting a Vulnerability

Please do not open a public issue for security problems.

Report privately through GitHub: go to the **Security** tab of this repository and choose **Report a vulnerability**. Include the affected version, steps to reproduce, and the impact you see.

I'll acknowledge reports as soon as I can and keep you updated as I work on a fix.
